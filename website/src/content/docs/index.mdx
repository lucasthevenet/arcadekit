arcadekit is one package of primitives for browser games made with [Effect](https://effect.website) 4, [Foldkit](https://foldkit.dev) and [Three.js](https://threejs.org). Install it below, then [make a game](/making-a-game): the concepts say how a game is put together, a guide covers each task, and each entry has a reference page.

## Games built on it

- [GRIMBONK](https://grimbonk.arcadekit.dev) is a grimdark third-person survivors-like, built on the published package. Play it in the browser.
- [The survivors demo](https://github.com/lucasthevenet/arcadekit/tree/main/examples/survivor-demo) is a survivors-like with co-op for two to four players. Its genre is in [`src/survivors`](https://github.com/lucasthevenet/arcadekit/tree/main/examples/survivor-demo/src/survivors).
- [The push-puzzle demo](https://github.com/lucasthevenet/arcadekit/tree/main/examples/push-puzzle-demo) is a Sokoban-like with undo. Its genre is in [`src/push-puzzle`](https://github.com/lucasthevenet/arcadekit/tree/main/examples/push-puzzle-demo/src/push-puzzle).

The demos don't publish: copy from them. [The repository's README](https://github.com/lucasthevenet/arcadekit#making-a-new-game) says how to make a new game, in an existing genre or a new one.
