# Sprites

`push-puzzle.png` and `push-puzzle.json` are generated by `scripts/generate-sprite-sheets.mjs` (run `pnpm sprites`): a cosy dungeon painted in code on a 16 px grid ([ADR-0015](../../../../docs/adr/0015-pixel-art-sprites-loaded-by-the-app.md)). The script is deterministic, so running it again rewrites the same bytes.

The JSON is Aseprite's export format with frames as a hash (`--format json-hash --list-tags`). Frame keys are `<tag> <index>`, like `player/walk 0`; `meta.frameTags` names each animation with its `from`/`to` frame and `direction: "forward"`; each frame has its `duration` in ms. Frames sit in the PNG with 1 px of transparent padding.

Every frame is 16x16. Tiles fill their frame. The box and the player are drawn over a floor tile and have transparent backgrounds; the player stands with its feet on the bottom row.

## Tags

| Tag | Size | Frames | What |
| --- | --- | --- | --- |
| `floor` | 16x16 | 3 | Flagstone variants |
| `wall` | 16x16 | 1 | The top of a wall, seen from above |
| `wall/face` | 16x16 | 1 | A wall's front face, for a wall with floor below it |
| `goal` | 16x16 | 1 | Floor with a gold rune |
| `hole` | 16x16 | 1 | An open pit |
| `hole/filled` | 16x16 | 1 | A pit with a box sunk in it |
| `box` | 16x16 | 1 | A wooden crate |
| `box/on-goal` | 16x16 | 1 | The crate on a goal: gold rim and corners |
| `player/idle` | 16x16 | 2 | Standing, facing right, breathing |
| `player/walk` | 16x16 | 4 | Walking right (the view flips it for left) |
| `player/up` | 16x16 | 4 | Walking up, seen from behind |
| `player/down` | 16x16 | 4 | Walking down, seen from the front |

## Replacing the art

Draw the sheet in Aseprite (or LibreSprite) with these tag names, then export with `File > Export Sprite Sheet`: "Hash" JSON data, "Tags" meta, 1 px border or shape padding, and the output named `push-puzzle.png` / `push-puzzle.json`. From the CLI: `aseprite -b art.aseprite --sheet push-puzzle.png --data push-puzzle.json --format json-hash --list-tags --shape-padding 1 --filename-format "{tag} {tagframe}"`.

To use a CC0 pack (Kenney's sokoban or dungeon tiles fit), pack its tiles into one PNG and write the JSON with the same tag names. Running `pnpm sprites` again overwrites these files, so stop using the script once you have real art.
