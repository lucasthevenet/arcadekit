# arcadekit

Primitives for building browser games on [Effect](https://effect.website) 4, around an entity component system: a simulation that gives the same result from the same inputs, with actions, saving, replays, input, sound and games of several players built on it.

`arcadekit` draws nothing itself. [`@arcadekit/three`](https://www.npmjs.com/package/@arcadekit/three) draws a game with Three.js.

> arcadekit is alpha: a minor version may break its interface, and the changelog says how.

## Installation

```sh
npm install arcadekit effect
```
