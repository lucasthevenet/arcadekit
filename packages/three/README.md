# @arcadekit/three

Draws an [arcadekit](https://www.npmjs.com/package/arcadekit) game with [Three.js](https://threejs.org). It is a plugin that runs between ticks and never changes the game it draws.

> @arcadekit/three is alpha: a minor version may break its interface, and the changelog says how.

## Installation

```sh
npm install @arcadekit/three arcadekit effect three
```
